Algorithmic Efficiency Principles

• Strict AVL Invariant: For every node $N$, $|h(N.left) - h(N.right)| \le 1$.

• O(log K) Search: Candidate interval search takes logarithmic time in the number of intervals $K$.

• Dense Compression: Contiguous packages are unified into interval nodes $[s, e]$, achieving near $O(1)$ space for sequential streams.

• Bridge Merge Speed: When an arrival connects two intervals, node deletion and rebalancing completes in $O(\log K)$ operations.
